**Key points:**
- Apple's own [App Store Connect release notes](https://developer.apple.com/app-store-connect/release-notes), dated October 5, 2026, confirm Creative Assets and the Asset Library are live.
- The Asset Library is a single hub for app previews, screenshots, and creative assets. Reused across a product page header, search results, and in-app events.
- Real-time preview shows exactly how an asset renders before anything publishes.
- This is a real launch, not another preview. Apple's own September page had listed the same feature as just "coming this fall."

A feature that was "coming this fall" is no longer coming. Apple's own release notes confirm it shipped.

## What actually changed on October 5

Apple's own App Store Connect release notes name three pieces. All live as of October 5, 2026. First, Creative Assets. Rich images and video, shown in a product page header and in relevant search results. Second, the Asset Library. A centralized hub in App Store Connect for managing every visual an app uses. Third, real-time preview. It shows how an asset actually renders on a product page and in search results, before it goes live.

| Piece | What it does, per Apple's own release notes |
|---|---|
| Creative Assets | Rich images and video in the product page header and search results |
| Asset Library | One place to manage and reuse assets, instead of uploading per placement |
| Real-time preview | Shows the actual rendered result before anything publishes |

## Why the Asset Library part matters most

A product page header image and a search-result creative used to mean two separate uploads. Even when they were meant to be the same asset. The Asset Library removes that duplication. Upload an asset once. Reuse it across the product page header, search results, and in-app events. Fewer uploads. One place to update an asset when creative needs to change, instead of hunting down every placement it touches.

Real-time preview closes a different gap. Before this, a team couldn't see exactly how a new creative asset would actually look in context. Not until it was already live, next to the app name and existing screenshots. Now that check happens before publishing. Not after.

> **Real-world scenario:** A team read Apple's September page. They saw Creative Assets listed as "coming this fall" and set the project aside for later in the quarter. Checking App Store Connect in early October, they found the feature already live, per Apple's own October 5 release notes. They uploaded their existing hero video and two product shots into the new Asset Library once. Then used real-time preview to confirm how the product page header actually looked, before publishing. The same assets now also show in relevant search results. No second upload needed.

## What to actually do about it

1. **Check App Store Connect directly rather than assuming it's still a preview.** Apple's own September page said "coming this fall." It's live now, as of the October 5 release notes.
2. **Consolidate existing assets into the Asset Library first.** One upload covering the product page header, search results, and in-app events beats separate uploads for each.
3. **Use real-time preview before publishing anything new.** It's the one part of this launch built specifically to catch a bad crop or an awkward placement before a reader ever sees it.
4. **Don't touch your existing screenshots or preview video.** Creative Assets is additive. Nothing about your current listing needs to change to adopt it.
